# Umbral RA 🎭📱

Una aplicación de **Realidad Aumentada** que celebra la riqueza culinaria y cultural del Día de Muertos en México. Apunta con tu cámara a los platillos tradicionales y descubre experiencias 3D únicas.

## ✨ Características

- **🎯 Image Tracking** con tecnología Vuforia
- **🍲 Renders 3D** de platillos tradicionales mexicanos
- **📱 Disponible exclusivamente** para Android
- **🎨 Experiencia cultural** inmersiva

## 🍽️ Experiencias Culinarias Incluidas

### Platos Fuertes
| Marcador | Experiencia 3D |
|----------|----------------|
| **Tamales** | Animación de tamales humeantes |
| **Chanchamitos** | Representación 3D tradicional |
| **Cerdo en Verde** | Plato animado con ingredientes |
| **Pejelagarto** | Pez característico en 3D |
| **Enchiladas** | Platillo colorido y animado |

### Bebidas y Postres
| Marcador | Experiencia 3D |
|----------|----------------|
| **Champurrado** | Bebida espumosa y humeante |
| **Pozoi** | Representación 3D de esta bebida |
| **Calavera de Azúcar** | Cráneo de azúcar animado |
| **Calavera de Armanto** | Ofrenda dulce tradicional |

### Elementos de Ofrenda
| Marcador | Experiencia 3D |
|----------|----------------|
| **Naranjas** | Frutas brillantes en la ofrenda |

## 🚀 Cómo Usar

1. **Descarga** la aplicación desde [Lanzamientos]
2. **Apunta** la cámara a cualquier imagen de los platillos listados
3. **Disfruta** de la experiencia de realidad aumentada

## 📱 Compatibilidad

- **Sistema**: Android 10+ (Quince Tart)
- **Dispositivos**: Compatible con la mayoría de smartphones Android
- **Cámara**: Requiere cámara posterior funcionando
- **Espacio**: 400MB de almacenamiento libre

## 🛠️ Tecnologías Utilizadas

- **Unity 2022.3 LTS**
- **Vuforia Engine**
- **C#** para scripts
- **Blender** para modelos 3D
- **Android SDK**
